Raster

1 Kästchen40 px
Jedes Kästchen = eine feste Einheit. Boden/Wand: klicken/ziehen zum Malen, nochmal klicken zum Entfernen. Haken/Schalter/Tür: jeder Klick setzt einen NEUEN Punkt (beliebig viele möglich). Start/Ziel gibt's je nur einmal.
Rechtsklick (auch gedrückt ziehen) = Radierer, egal welches Werkzeug aktiv ist.
Das Level wächst nach rechts automatisch mit, sobald du nah am Rand malst – oder per „+20 Spalten“. Mausrad scrollt seitlich.
Bewegung ➜: Erst ganz normal Boden (oder Wand) malen. Dann mit „Bewegung“ auf ein Kästchen davon klicken und zum Zielpunkt ziehen. Das ganze zusammenhängende Stück (gleiche Sorte) fährt dann immer hin und zurück. Später nochmal ändern: ohne Ziehen draufklicken = auswählen (gelb) – dann Tempo/„per Schalter“ oben ändern, neu ziehen = neues Ziel, „✕ Bewegung entfernen“ oder Entf = löschen. Funktioniert genauso mit einem Haken: vom Haken aus ziehen → der Haken pendelt (auch per Schalter). „per Schalter“ vor dem Ziehen wählen: dann steht das Stück still, bis jemand den Schalter (Hebel) mit dieser Nummer betätigt, und fährt ab da dauerhaft hin und her. Ohne Schalter fährt es von Anfang an. Stirbt jemand, springen alle bewegten Teile zurück an den Start (mit Schalter warten sie dann wieder). Tipp: bewegtes Stück darf nicht direkt an gleichartigen festen Boden grenzen, sonst gehört der mit dazu.

Haken-Radius (in Kästchen) vor dem Setzen oben einstellen. Mit dem Haken-Werkzeug auf einen vorhandenen Haken klicken übernimmt den eingestellten Radius.
StachelnBerührung = zurück zum Checkpoint
Richtung der Spitzen oben bei „Spitzen“ wählen (z. B. ▼ unter eine Decke, ◀/▶ an Wände). Mit dem Stacheln-Werkzeug auf vorhandene Stacheln klicken dreht sie um 90°.
Schalter sind im Spiel kleine Hebel in der Farbe ihrer Nummer. Man betätigt sie mit einer Taste (Affe J, Schweinchen Num 2, Controller Kreis). Den Schalter auf das Kästchen direkt über dem Boden setzen.
Checkpoints0 gesetzt
Checkpoint auf das Kästchen direkt ÜBER dem Boden setzen (wie Start/Ziel). Er zählt erst, wenn BEIDE vorbei sind – dann geht die Fahne hoch. Stirbt jemand, starten beide am letzten erreichten Checkpoint (sonst am Start).
Münzen0 gesetzt
Blaue Münzen kann nur der Affe einsammeln, pinke nur das Schweinchen, goldene beide. Farbe oben bei „Farbe“ wählen; mit dem Münz-Werkzeug auf eine vorhandene Münze klicken wechselt ihre Farbe. Das Ziel zählt erst mit 10 Münzen (hat das Level weniger als 10, müssen alle gesammelt werden).
Schalter/Türgleiche Zahl = verknüpft
Der Hebel ist ein Ein/Aus-Schalter: 1× betätigen = Tür auf / Bewegung fährt, nochmal = Tür zu / Bewegung bleibt stehen. Türen bleiben offen, bis der Hebel nochmal betätigt wird.
Vor dem Setzen von Schalter/Tür oben die Verknüpfungs-Nummer wählen – Schalter und Tür mit derselben Nummer gehören zusammen. Eine Nummer kann auch mehrfach vorkommen (z. B. 2 Schalter, 1 Tür).

Export

Auf GitHub speichern

Überschreibt dieses Level im Projekt (Spiel- und Editor-Datei). Nach 1–2 Minuten ist es online – dann im Spiel Strg + F5.
Zugangsschlüssel (einmalig einrichten)
  1. Auf GitHub einloggen und neuen Schlüssel anlegen („Fine-grained token“).
  2. Name z. B. „Level-Editor“, Ablauf z. B. 1 Jahr.
  3. „Repository access“: Only select repositories → koopgame.
  4. „Permissions“ → „Repository permissions“ → Contents: Read and write.
  5. „Generate token“, den Schlüssel kopieren und hier einfügen.
Der Schlüssel bleibt nur in diesem Browser gespeichert und darf nur dieses eine Projekt ändern.
